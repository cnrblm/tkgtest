01

Web uygulaması nasıl çalışır?

10 dakika

Bir web uygulamasında iki taraf vardır. İstemci (tarayıcı, mobil uygulama ya da başka bir program) bir istek gönderir. Sunucu isteği işler ve bir yanıt döndürür. Bu hafta sunucuyu biz yazıyoruz, Python'un Flask kütüphanesiyle.

AdımKim?Ne olur?
1İstemciİstek gönderir: “GET /kitaplar/1, yani 1 numaralı kitabı ver.”
2FlaskAdrese bakar, /kitaplar/1 için yazılmış fonksiyonu bulur.
3Bizim fonksiyonumuzKitabı bulur ve bir sözlük döndürür.
4FlaskSözlüğü JSON metnine çevirir, durum kodunu ekler (200) ve yanıtı gönderir.
5İstemciYanıtı okur: tarayıcı ekranda gösterir, bir program içindeki veriyi kullanır.

Bir web sayfası insanlar için HTML döndürür. Bir API (Application Programming Interface) ise programlar için veri döndürür, çoğunlukla JSON biçiminde. Telefonunuzdaki bir uygulama arka planda böyle API'lerle konuşur. Biz de bir API yazacağız.

02

HTTP: metot ve durum kodu

15 dakika

İstemci ile sunucu HTTP denen kurallarla konuşur. Her istekte bir metot ve bir adres bulunur; bazı isteklerde bir de gövde (gönderilen veri) olur. Metot, ne yapılmak istendiğini söyler:

MetotNe için?Örnek
GETOkumakGET /kitaplar: bütün kitapları verbu hafta
POSTYeni kayıt eklemekPOST /kitaplar (gövdede yeni kitap)bu hafta
PUTGüncellemekPUT /kitaplar/1ileride
DELETESilmekDELETE /kitaplar/1ileride

Her yanıtta üç sayılık bir durum kodu vardır. İlk rakam sonucun türünü söyler: 2 ile başlayanlar başarılı, 4 ile başlayanlar istemcinin hatası, 5 ile başlayanlar sunucunun hatası.

KodAdıNe zaman?
200OKİstek başarılı, istenen veri gövdede.
201CreatedYeni kayıt oluşturuldu (POST).
400Bad RequestGönderilen veri hatalı: örneğin kitabın başlığı yok.
404Not FoundBöyle bir kayıt ya da adres yok.
405Method Not AllowedAdres var ama bu metot desteklenmiyor.
500Internal Server ErrorSunucudaki kod çöktü. Sunucunun hatası; kullanıcının değil.
Test açısından: bir API testinde iki şey kontrol edilir: doğru durum kodu geldi mi, gövdede doğru veri var mı? 404 ve 400 de birer sonuçtur; “hata vermesi gereken yerde doğru hatayı veriyor mu?” sorusu, pytest 101'deki pytest.raises'ın API'deki karşılığıdır.
03

JSON

10 dakika

JSON, verinin metin olarak yazılmış hâlidir. Python'daki sözlük ve listelere çok benzer; zaten pytest 102'deki sözlük bölümünü biliyorsanız JSON'u da biliyorsunuz. Farklar küçük:

PythonJSON
Sözlük {"ad": "Ali"}Nesne {"ad": "Ali"}
Liste [1, 2, 3]Dizi [1, 2, 3]
True, Falsetrue, false
Nonenull
'tek' ya da "çift" tırnakYalnızca "çift" tırnak
json_deneme.py
import json

ogrenci = {"ad": "Ali", "not": 85, "gecti": True, "devamsizlik": None}
metin = json.dumps(ogrenci)    # sözlük → JSON metni
print(metin)
print(type(metin))

geri = json.loads(metin)       # JSON metni → sözlük
print(geri["not"])
{"ad": "Ali", "not": 85, "gecti": true, "devamsizlik": null} <class 'str'> 85

json.dumps sonucu bir metin (str); ağ üzerinden metin gönderilebilir. Flask bu çevirmeyi bizim yerimize yapar: fonksiyondan bir sözlük döndürürsünüz, istemciye JSON gider.

05

Route'lar ve 404

15 dakika

Şimdi asıl uygulamaya geçelim. Kitaplar şimdilik bir listede, sözlük olarak duruyor. app.py'nin içeriğini şununla değiştirin:

app.py
from flask import Flask

app = Flask(__name__)
app.json.ensure_ascii = False
app.json.sort_keys = False

kitaplar = [
    {"id": 1, "baslik": "Kürk Mantolu Madonna", "yazar": "Sabahattin Ali", "yil": 1943},
    {"id": 2, "baslik": "Tutunamayanlar", "yazar": "Oğuz Atay", "yil": 1972},
    {"id": 3, "baslik": "Kuyucaklı Yusuf", "yazar": "Sabahattin Ali", "yil": 1937},
]


@app.get("/kitaplar")
def kitap_listesi():
    return kitaplar


@app.get("/kitaplar/<int:kitap_id>")
def kitap_getir(kitap_id):
    for kitap in kitaplar:
        if kitap["id"] == kitap_id:
            return kitap
    return {"hata": "kitap bulunamadı"}, 404


if __name__ == "__main__":
    app.run(debug=True)
  • app.json.sort_keys = False: alanlar bizim yazdığımız sırada görünsün (yoksa Flask alfabetik sıralar).
  • <int:kitap_id>: adresin bu kısmı bir tam sayıdır ve fonksiyona kitap_id parametresi olarak gelir. /kitaplar/2 isteğinde kitap_id = 2.
  • return {...}, 404: gövde ile durum kodu birlikte döndürülür. Kod yazılmazsa 200 olur.

Tarayıcıda http://127.0.0.1:5000/kitaplar ve http://127.0.0.1:5000/kitaplar/1 adreslerini deneyin. Tarayıcı gövdeyi gösterir ama durum kodunu göstermez, ve yalnızca GET isteği gönderebilir. API'leri denemek için Postman kullanacağız.

Postman ile istek göndermek

  1. postman.com/downloads adresinden Postman'i indirip kurun. Açılışta oturum açmanızı isterse ücretsiz bir hesap açın.
  2. Yeni bir istek sekmesi açın (+ düğmesi).
  3. Soldaki listeden metodu seçin (GET), yanındaki kutuya adresi yazın.
  4. Send'e basın. Yanıt alt yarıda görünür: sağ üstte Status (durum kodu), altında Body (gövde). Headers sekmesi yanıtın başlıklarını gösterir.

Sunucu çalışırken (python app.py çalışan terminali kapatmayın) şu isteği gönderin:

MetotAdres
GEThttp://127.0.0.1:5000/kitaplar/1
Status: 200 OK { "id": 1, "baslik": "Kürk Mantolu Madonna", "yazar": "Sabahattin Ali", "yil": 1943 }

Adresin sonunu 99 yapıp yeniden gönderin:

Status: 404 NOT FOUND { "hata": "kitap bulunamadı" }

99 numaralı kitap olmadığı için bizim yazdığımız 404 yanıtı geldi. /kitaplar/abc denerseniz yine 404 gelir ama bu kez Flask'ın kendi HTML sayfası: abc bir tam sayı olmadığı için adres hiçbir route'a uymadı, fonksiyonumuz hiç çalışmadı.

Headers sekmesine bakın: Content-Type: application/json satırı, gövdenin JSON olduğunu söyler. /kitaplar/abc'nin yanıtında ise text/html görürsünüz.
06

Sorgu parametresi

10 dakika

Adresin sonundaki ?'den sonraki kısım sorgu parametresidir: /kitaplar?yazar=ali. Listeyi filtrelemek için kullanılır. Önce ilk satırı from flask import Flask, request yapın; request, gelen isteğin bilgilerini taşır. Sonra kitap_listesi fonksiyonunu şununla değiştirin:

app.py (kitap_listesi)
@app.get("/kitaplar")
def kitap_listesi():
    yazar = request.args.get("yazar")
    if yazar is None:
        return kitaplar
    sonuc = []
    for kitap in kitaplar:
        if yazar.lower() in kitap["yazar"].lower():
            sonuc.append(kitap)
    return sonuc

request.args.get("yazar") adresteki yazar değerini verir; adreste yoksa None. Büyük/küçük harf fark etmesin diye iki taraf da küçültülüyor. Tarayıcıda http://127.0.0.1:5000/kitaplar?yazar=ali:

[ { "id": 1, "baslik": "Kürk Mantolu Madonna", "yazar": "Sabahattin Ali", "yil": 1943 }, { "id": 3, "baslik": "Kuyucaklı Yusuf", "yazar": "Sabahattin Ali", "yil": 1937 } ]

?yazar=pamuk denerseniz [] gelir, durum kodu 200. Boş liste bir hata değildir: adres doğru, yalnızca filtreye uyan kitap yok. 404 ise “böyle bir şey yok” demektir. Bu fark, testlerde sık sorulan bir sınır durumudur.

07

POST ile veri eklemek

20 dakika

Yeni kitap eklemek için istemci kitabı JSON olarak isteğin gövdesinde gönderir. Sunucu önce veriyi doğrular: başlık yoksa 400, varsa kitabı ekleyip 201 döndürür. app.py'ye, if __name__ satırının üstüne ekleyin:

app.py (ekleyin)
@app.post("/kitaplar")
def kitap_ekle():
    veri = request.get_json(silent=True)
    if not veri or not veri.get("baslik"):
        return {"hata": "baslik zorunlu"}, 400
    kitap = {
        "id": len(kitaplar) + 1,
        "baslik": veri["baslik"],
        "yazar": veri.get("yazar", ""),
        "yil": veri.get("yil"),
    }
    kitaplar.append(kitap)
    return kitap, 201
  • @app.post: aynı adres (/kitaplar), farklı metot. GET gelince kitap_listesi, POST gelince kitap_ekle çalışır.
  • request.get_json(silent=True): gövdedeki JSON'u sözlüğe çevirir. Gövde JSON değilse hata yerine None verir (silent=True).
  • veri.get("yazar", ""): sözlükte yazar yoksa boş metin kullan.

Tarayıcının adres çubuğu her zaman GET gönderir; POST'u Postman ile deneyin. Bu kez gövdeye de bir şey yazacağız:

  1. Yeni bir istek sekmesi açın, metodu POST yapın, adrese http://127.0.0.1:5000/kitaplar yazın.
  2. Adresin altındaki Body sekmesine geçin, raw'ı seçin; sağında açılan listeden Text yerine JSON'u seçin.
  3. Gövdeyi kutuya yapıştırıp Send'e basın.
Postman → Body → raw → JSON
{"baslik": "Beyaz Kale", "yazar": "Orhan Pamuk", "yil": 1985}
Status: 201 CREATED { "id": 4, "baslik": "Beyaz Kale", "yazar": "Orhan Pamuk", "yil": 1985 }

Şimdi gövdeyi başlıksız bir kitapla değiştirip yeniden gönderin:

Postman → Body → raw → JSON
{"yazar": "Orhan Pamuk"}
Status: 400 BAD REQUEST { "hata": "baslik zorunlu" }

JSON'u seçmek, isteğe Content-Type: application/json başlığını ekler (istekteki Headers sekmesinde görebilirsiniz). Flask, gövdenin JSON olduğunu bu başlıktan anlar.

Şimdi tarayıcıda /kitaplar'ı yenileyin: Beyaz Kale listede, 4 kitap var. Sunucuyu durdurup yeniden başlatın ve tekrar bakın: yine 3 kitap. Kitaplar yalnızca bellekteki bir listede duruyor; sunucu kapanınca eklenenler kaybolur. Kalıcı olması için bir veritabanı gerekir; onu Flask 102'de ekleyeceğiz.

08

Sık karşılaşılan hatalar

Başvuru bölümü

ModuleNotFoundError: No module named 'flask'

Flask kurulu değil ya da başka bir Python'a kurulu. python -m pip install flask; aynı terminalde python app.py.

Address already in use / Port 5000 is in use by another program

Çoğu zaman başka bir terminalde sunucu zaten çalışıyor; o terminalde Ctrl+C yapın. macOS'ta AirPlay Alıcısı da bu portu kullanabilir: Sistem Ayarları'nda “AirPlay Alıcısı”nı kapatın ya da son satırı app.run(debug=True, port=5001) yapıp adreslerde 5001 kullanın.

macOS: localhost:5000 açınca 403 Forbidden

İstek Flask'a değil AirPlay'e gitti. Tarayıcıda da Postman'de de http://127.0.0.1:5000 yazın.

404 Not Found (Flask'ın HTML sayfası)

Adres hiçbir route'a uymadı. Yazımı kontrol edin: /kitaplar/ (sondaki /) ve /kitaplar/abc (sayı değil) uymaz. Bizim yazdığımız 404 ise JSON döner: {"hata": "kitap bulunamadı"}.

405 Method Not Allowed

Adres var ama o metot için route yok. Örneğin /kitaplar/1'e DELETE ya da /'e POST. Tarayıcının adres çubuğu her zaman GET gönderir; POST'u Postman'de ya da testte deneyin. Postman'de metodu doğru seçtiğinizden emin olun.

Başlığı gönderdiğim hâlde 400 baslik zorunlu

Postman'de Body → raw seçili ama yanındaki listede JSON yerine Text kalmış. O zaman Content-Type: application/json başlığı gönderilmez, gövde JSON sayılmaz ve get_json(silent=True) None döner.

Postman: connect ECONNREFUSED 127.0.0.1:5000

Sunucu çalışmıyor. python app.py çalışan terminal açık mı? Ctrl+C ile durdurduysanız ya da kodda bir hata yüzünden kapandıysa yeniden başlatın.

Türkçe harfler \u00fc gibi görünüyor

app.json.ensure_ascii = False satırı eksik. Bu satır yoksa da JSON doğrudur; yalnızca okuması zordur.
