01

Nerede kalmıştık?

5 dakika

Flask 101'in sonunda flask-deneme klasöründe bir app.py vardı: kitapları listeleyen, tek kitap getiren (yoksa 404) ve POST ile kitap ekleyen (başlık yoksa 400) küçük bir API. Bu sayfada aynı klasörde devam ediyoruz. Dosyanız elinizde değilse aşağıdan alın.

app.py (Flask 101'in sonundaki hâli)
app.py
from flask import Flask, request

app = Flask(__name__)
app.json.ensure_ascii = False
app.json.sort_keys = False

kitaplar = [
    {"id": 1, "baslik": "Kürk Mantolu Madonna", "yazar": "Sabahattin Ali", "yil": 1943},
    {"id": 2, "baslik": "Tutunamayanlar", "yazar": "Oğuz Atay", "yil": 1972},
    {"id": 3, "baslik": "Kuyucaklı Yusuf", "yazar": "Sabahattin Ali", "yil": 1937},
]


@app.get("/kitaplar")
def kitap_listesi():
    yazar = request.args.get("yazar")
    if yazar is None:
        return kitaplar
    sonuc = []
    for kitap in kitaplar:
        if yazar.lower() in kitap["yazar"].lower():
            sonuc.append(kitap)
    return sonuc


@app.get("/kitaplar/<int:kitap_id>")
def kitap_getir(kitap_id):
    for kitap in kitaplar:
        if kitap["id"] == kitap_id:
            return kitap
    return {"hata": "kitap bulunamadı"}, 404


@app.post("/kitaplar")
def kitap_ekle():
    veri = request.get_json(silent=True)
    if not veri or not veri.get("baslik"):
        return {"hata": "baslik zorunlu"}, 400
    kitap = {
        "id": len(kitaplar) + 1,
        "baslik": veri["baslik"],
        "yazar": veri.get("yazar", ""),
        "yil": veri.get("yil"),
    }
    kitaplar.append(kitap)
    return kitap, 201


if __name__ == "__main__":
    app.run(debug=True)

Sunucuyu başlatın (python app.py) ve Postman'de GET http://127.0.0.1:5000/kitaplar isteğinin üç kitap döndürdüğünü görün. Sonra sunucuyu Ctrl+C ile durdurun; testler için sunucunun açık olması gerekmiyor.

02

Test istemcisi

20 dakika

Her değişiklikten sonra Postman'de istekleri tek tek gönderip yanıtlara gözle bakmak, pytest öncesi print ile test etmeye benziyor. Flask'ın test istemcisi, sunucu çalıştırmadan uygulamaya istek gönderir. Böylece API testleri de sıradan pytest testleri olur:

04

Şablonlar: JSON yerine HTML sayfa

20 dakika

API, programlar için JSON döndürür. İnsanların tarayıcıda okuyacağı bir sayfa için ise HTML gerekir. HTML'i Python kodunun içinde metin olarak birleştirmek hem zor hem tehlikelidir. Bunun yerine HTML'i ayrı bir dosyaya, bir şablona yazarız; değişecek yerleri işaretleriz, Flask doldurur. Flask'ın şablon dili Jinja'dır.

flask-deneme klasöründe templates adında bir klasör açın. Flask şablonları yalnızca bu adlı klasörde arar. İçine üç dosya koyun:

templates/kitaplar.html
<!doctype html>
<html lang="tr">
<head>
  <meta charset="utf-8">
  <title>Kütüphane</title>
</head>
<body>
  <h1>Kitaplar</h1>
  <ul>
    {% for kitap in kitaplar %}
    <li><a href="/kitap/{{ kitap.id }}">{{ kitap.baslik }}</a> ({{ kitap.yazar }})</li>
    {% else %}
    <li>Henüz kitap yok.</li>
    {% endfor %}
  </ul>
</body>
</html>
templates/kitap.html
<!doctype html>
<html lang="tr">
<head>
  <meta charset="utf-8">
  <title>{{ kitap.baslik }}</title>
</head>
<body>
  <h1>{{ kitap.baslik }}</h1>
  <p>Yazar: {{ kitap.yazar }}</p>
  <p>Yıl: {{ kitap.yil }}</p>
  <p><a href="/">Bütün kitaplar</a></p>
</body>
</html>

ŞablondaAnlamı
{{ kitap.baslik }}Değeri buraya yaz. Sözlüğün baslik anahtarı, kitap["baslik"] ile aynı.
{% for kitap in kitaplar %} … {% endfor %}Listedeki her kitap için aradaki satırı tekrarla. Python'daki for gibi, ama girinti yerine endfor ile kapanır.
{% else %}Liste boşsa bunu yaz.

Şimdi app.py'de ilk satırı from flask import Flask, render_template, request yapın ve if __name__ satırının üstüne iki route ekleyin:

render_template("kitaplar.html", kitaplar=kitaplar): şablonu bul, içindeki kitaplar adına bizim listemizi ver, sonucu HTML olarak döndür. Sunucuyu başlatıp tarayıcıda http://127.0.0.1:5000/ adresini açın; sayfanın kaynağı (Ctrl+U) şöyledir:

<!doctype html> <html lang="tr"> <head> <meta charset="utf-8"> <title>Kütüphane</title> </head> <body> <h1>Kitaplar</h1> <ul> <li><a href="/kitap/1">Kürk Mantolu Madonna</a> (Sabahattin Ali)</li> <li><a href="/kitap/2">Tutunamayanlar</a> (Oğuz Atay)</li> <li><a href="/kitap/3">Kuyucaklı Yusuf</a> (Sabahattin Ali)</li> </ul> </body> </html>

Bir kitaba tıklayınca /kitap/2 gibi ayrıntı sayfası açılır. /kitap/99 ise “Kitap bulunamadı” sayfasını 404 koduyla döndürür. Şablondaki boş satırlar Jinja komutlarının kaldığı yerlerdir; tarayıcı onları göstermez.

Aynı veri, iki biçim: /kitaplar programlara JSON, / insanlara HTML veriyor. İkisi de aynı kitaplar listesini kullanıyor.

Şablonu test etmek

15 dakika

Sayfa testi de API testi gibidir; tek fark, yanıt JSON değil metindir. yanit.get_data(as_text=True) sayfanın HTML'ini metin olarak verir; içinde beklenen şeyin geçip geçmediğine in ile bakarız:

def test_ana_sayfa_kitaplari_listeler():
    verileri_sifirla()
    client = app.test_client()
    yanit = client.get("/")
    assert yanit.status_code == 200
    html = yanit.get_data(as_text=True)
    assert "Tutunamayanlar" in html

    yanit = client.get("/kitap/99")

    assert "Kitap bulunamadı" in yanit.get_data(as_text=True)

Son test neden önemli?

Bir kullanıcı kitap başlığı olarak <script>alert(1)</script> gönderirse ve sayfa bunu olduğu gibi yazarsa, sayfayı açan herkesin tarayıcısında o kod çalışır. Bu, en yaygın web güvenlik açıklarından biridir (XSS). Jinja, {{ }} içindeki değerdeki < ve > işaretlerini kendiliğinden &lt; ve &gt; yapar (kaçışlama). Tarayıcı bunları kod olarak değil metin olarak gösterir. Son test bu korumanın yerinde olduğunu kontrol ediyor.

Deneyin: kitap.html'de <h1>{{ kitap.baslik }}</h1> satırını <h1>{{ kitap.baslik|safe }}</h1> yapın. |safe “bu değer güvenli, kaçışlama” demektir:

Test, güvenlik açığını yakaladı. Devam etmeden önce |safe'i silin.

|safe kullanmayın. Kullanıcıdan gelen hiçbir değeri |safe ile yazmayın. Bu tür açıkları arayan araçlara 11. haftada bakacağız.
06

Veritabanı: SQLite

20 dakika

Flask 101'de şunu görmüştük: POST ile eklenen kitap, sunucu kapanınca kayboluyor, çünkü kitaplar bellekteki bir listede. Kalıcı olması için bir veritabanı gerekir. SQLite, verileri tek bir dosyada tutan küçük bir veritabanıdır; Python ile birlikte gelir (import sqlite3), ayrıca kurulmaz. SQL'i biliyorsunuz; burada yalnızca Python'dan nasıl kullanıldığına bakacağız.

app.py'nin tamamını şununla değiştirin. Route adresleri ve şablonlar aynı kalıyor; değişen, verinin nereden okunduğu. Bir de PUT ve DELETE ekliyoruz (7. bölüm).

app.py
import os
import sqlite3

from flask import Flask, render_template, request

app = Flask(__name__)
app.json.ensure_ascii = False
app.json.sort_keys = False
app.config["VERITABANI"] = "kutuphane.db"

BASLANGIC_KITAPLARI = [
    ("Kürk Mantolu Madonna", "Sabahattin Ali", 1943),
    ("Tutunamayanlar", "Oğuz Atay", 1972),
    ("Kuyucaklı Yusuf", "Sabahattin Ali", 1937),
]


def baglan():
    baglanti = sqlite3.connect(app.config["VERITABANI"])
    baglanti.row_factory = sqlite3.Row
    return baglanti


def verileri_sifirla():
    baglanti = baglan()
    baglanti.execute("DROP TABLE IF EXISTS kitaplar")
    baglanti.execute(
        "CREATE TABLE kitaplar"
        " (id INTEGER PRIMARY KEY, baslik TEXT, yazar TEXT, yil INTEGER)"
    )
    for kitap in BASLANGIC_KITAPLARI:
        baglanti.execute(
            "INSERT INTO kitaplar (baslik, yazar, yil) VALUES (?, ?, ?)", kitap
        )
    baglanti.commit()
    baglanti.close()


def tum_kitaplar():
    baglanti = baglan()
    satirlar = baglanti.execute("SELECT * FROM kitaplar ORDER BY id").fetchall()
    baglanti.close()
    sonuc = []
    for satir in satirlar:
        sonuc.append(dict(satir))
    return sonuc


def kitap_bul(kitap_id):
    baglanti = baglan()
    satir = baglanti.execute(
        "SELECT * FROM kitaplar WHERE id = ?", (kitap_id,)
    ).fetchone()
    baglanti.close()
    if satir is None:
        return None
    return dict(satir)


@app.get("/kitaplar")
def kitap_listesi():
    return tum_kitaplar()


@app.get("/kitaplar/<int:kitap_id>")
def kitap_getir(kitap_id):
    kitap = kitap_bul(kitap_id)
    if kitap is None:
        return {"hata": "kitap bulunamadı"}, 404
    return kitap


@app.post("/kitaplar")
def kitap_ekle():
    veri = request.get_json(silent=True)
    if not veri or not veri.get("baslik"):
        return {"hata": "baslik zorunlu"}, 400
    baglanti = baglan()
    imlec = baglanti.execute(
        "INSERT INTO kitaplar (baslik, yazar, yil) VALUES (?, ?, ?)",
        (veri["baslik"], veri.get("yazar", ""), veri.get("yil")),
    )
    baglanti.commit()
    yeni_id = imlec.lastrowid
    baglanti.close()
    return kitap_bul(yeni_id), 201


@app.put("/kitaplar/<int:kitap_id>")
def kitap_guncelle(kitap_id):
    if kitap_bul(kitap_id) is None:
        return {"hata": "kitap bulunamadı"}, 404
    veri = request.get_json(silent=True)
    if not veri or not veri.get("baslik"):
        return {"hata": "baslik zorunlu"}, 400
    baglanti = baglan()
    baglanti.execute(
        "UPDATE kitaplar SET baslik = ?, yazar = ?, yil = ? WHERE id = ?",
        (veri["baslik"], veri.get("yazar", ""), veri.get("yil"), kitap_id),
    )
    baglanti.commit()
    baglanti.close()
    return kitap_bul(kitap_id)


@app.delete("/kitaplar/<int:kitap_id>")
def kitap_sil(kitap_id):
    if kitap_bul(kitap_id) is None:
        return {"hata": "kitap bulunamadı"}, 404
    baglanti = baglan()
    baglanti.execute("DELETE FROM kitaplar WHERE id = ?", (kitap_id,))
    baglanti.commit()
    baglanti.close()
    return {"mesaj": "kitap silindi"}


@app.get("/")
def ana_sayfa():
    return render_template("kitaplar.html", kitaplar=tum_kitaplar())


@app.get("/kitap/<int:kitap_id>")
def kitap_sayfasi(kitap_id):
    kitap = kitap_bul(kitap_id)
    if kitap is None:
        return render_template("bulunamadi.html"), 404
    return render_template("kitap.html", kitap=kitap)


if __name__ == "__main__":
    if not os.path.exists(app.config["VERITABANI"]):
        verileri_sifirla()
    app.run(debug=True)

15 dakika

Flask 101'de dört metottan ikisini kullanmıştık. Uygulama artık dördünü de destekliyor; bir kaydın oluşturulması, okunması, güncellenmesi ve silinmesine kısaca CRUD denir:

Postman'de metodu PUT, adresi http://127.0.0.1:5000/kitaplar/2 yapın; gövdeye (Body → raw → JSON) kitabın yeni hâlini yazın:

Postman → Body → raw → JSON

Test için ipucu: DELETE'in 200 döndürmesi kitabın gerçekten silindiğini göstermez. Silindiğini anlamanın yolu, ardından GET ile o kitabı istemek ve 404 almaktır. Bir sonraki bölümde testler bunu yapıyor.
