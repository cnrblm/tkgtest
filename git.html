01

GitHub hesabı açın

5 dakika · Hesabınız zaten varsa bu adımı atlayın, yalnızca okul e-postanızı eklediğinizden emin olun.

  1. github.com/signup adresine gidin.
  2. Kullanıcı adını bir iş görüşmesinde gösterebileceğiniz şekilde seçin: ayseyilmaz iyi, xX_hacker06_Xx değil. Bu ad dönem boyunca ve sonrasında portföyünüz olacak.
  3. Kayıttan sonra Settings → Emails sayfasından okul e-postanızı (@ogr...edu.tr) ekleyin ve gelen bağlantıyla doğrulayın.
  4. Settings → Password and authentication altından iki adımlı doğrulamayı (2FA) açın. Telefonunuzdaki bir doğrulayıcı uygulaması yeterli.
  5. Settings → Public profile altında adınızı ve soyadınızı gerçek haliyle yazın. Öğrenci paketi başvurusunda belgedeki adla karşılaştırılır.
02

GitHub Öğrenci Paketi'ne başvurun

10 dakika · Onay birkaç saat ile birkaç gün arası sürebilir; beklerken sonraki adımlara geçin.

Öğrenci olduğunuzu doğruladığınızda GitHub Pro ve birçok geliştirici aracı ücretsiz açılır. Başvuru için gerekenler:

  • 13 yaşından büyük, diploma veren bir programa kayıtlı olmak
  • Doğrulanmış okul e-postası (1. adımda eklediniz)
  • Güncel tarihli bir öğrencilik belgesi

Belgeyi hazırlayın

En sorunsuz belge, e-Devlet'ten alınan Öğrenci Belgesi'dir (YÖK, “Öğrenci Belgesi Sorgulama”). PDF'i açıp ekran görüntüsünü alın; üzerinde adınız, üniversite adı ve bugünün tarihi okunur olmalı. Öğrenci kimlik kartı da kabul edilir, ama üzerinde geçerlilik tarihi yoksa genellikle reddedilir.

Başvurun

  1. github.com/settings/education/benefits sayfasını açın.
  2. Start an application düğmesine basın, rol olarak Student seçin.
  3. Okulunuzu seçin, okul e-postanızı işaretleyin, belgeyi yükleyin ve Submit application ile gönderin.
Reddedilirseniz: en sık nedenler bulanık fotoğraf, tarihsiz belge ve profildeki adın belgedekiyle uyuşmamasıdır. Düzeltip tekrar başvurabilirsiniz. Sonucu aynı sayfadan takip edebilirsiniz.
03

Git'i kurun

5–10 dakika

git-scm.com adresinden Git for Windows'u indirip kurun. Kurulumdaki ekranlarda varsayılanları bırakabilirsiniz; tek değişiklik: varsayılan editör sorusunda Visual Studio Code'u seçin. Kurulum, GitHub girişini kolaylaştıran Git Credential Manager'ı da getirir.

Kurulumdan sonra Git Bash ya da VS Code terminalini açın.

Terminal'i açın ve aşağıdaki komutu çalıştırın. Git yoksa macOS geliştirici araçlarını kurmayı önerir; Install deyin.

Terminal
xcode-select --install
Terminal (Ubuntu / Debian)
sudo apt update && sudo apt install -y git

Kurulumu doğrulayın:

Terminal
git --version
git version 2.4x.x

Bir sürüm numarası görüyorsanız tamam. “command not found” görüyorsanız terminali kapatıp yeniden açın.

04

Git'e kendinizi tanıtın

2 dakika · Her bilgisayarda bir kez yapılır.

Her commit'in üzerine yazan kişinin adı ve e-postası işlenir. E-posta, GitHub hesabınızdakiyle aynı olmalı; yoksa commit'leriniz profilinizde görünmez.

Terminal
git config --global user.name "Ayşe Yılmaz"
git config --global user.email "ayse.yilmaz@ogr.universite.edu.tr"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

Kontrol edin:

Terminal
git config --global --list
05

Bilgisayarınızdan GitHub'a giriş yapın

5 dakika

GitHub, terminalden şifreyle girişi kabul etmez. En kolay yol GitHub CLI (gh) aracıdır: bir kez giriş yaparsınız, sonra git push sorunsuz çalışır.

  1. cli.github.com adresinden işletim sisteminize uygun sürümü kurun (Windows'ta winget install GitHub.cli, macOS'ta brew install gh).
  2. Terminali kapatıp yeniden açın ve şu komutu çalıştırın:
Terminal
gh auth login

Sorulara şu cevapları verin: GitHub.com → HTTPS → Git için kimlik bilgisi kullanılsın mı: Yes → Login with a web browser. Ekrandaki 8 haneli kodu tarayıcıda açılan sayfaya girin.

✓ Logged in as ayseyilmaz
Windows'ta gh kuramadıysanız: sorun değil. Git for Windows ile gelen Credential Manager, ilk git push sırasında tarayıcıda bir giriş penceresi açar; orada onaylamanız yeterli.
06

İlk deponuzu oluşturun ve commit'leyin

10 dakika

GitHub'da boş bir depo açın

  1. github.com/new sayfasına gidin.
  2. Repository name: kalite-lab, görünürlük: Public.
  3. “Add a README”, “.gitignore” ve “license” seçeneklerini boş bırakın. Bu dosyaları kendimiz ekleyeceğiz; burada eklerseniz ilk push'ta çakışma yaşarsınız.
  4. Create repository.

Bilgisayarınızda projeyi hazırlayın

Terminal
mkdir kalite-lab
cd kalite-lab
git init
Initialized empty Git repository in .../kalite-lab/.git/

VS Code'da bu klasörü açın (code .) ve üç dosya oluşturun:

ortalama.py
def ortalama(notlar: list[float]) -> float:
    """Not listesinin aritmetik ortalamasını döndürür."""
    if not notlar:
        raise ValueError("Not listesi boş olamaz")
    return sum(notlar) / len(notlar)


if __name__ == "__main__":
    print(ortalama([70, 85, 90]))
README.md
# kalite-lab

Yazılım Kalite Güvencesi ve Testi dersi çalışma deposu.
.gitignore
# Python
__pycache__/
*.pyc
.venv/

# Editör ve işletim sistemi
.vscode/
.DS_Store
Thumbs.db

Durumu görün, ekleyin, commit'leyin

Terminal
git status
Untracked files: .gitignore README.md ortalama.py

git status en sık kullanacağınız komut: ne değişti, ne eklenmeye hazır, onu söyler. Şimdi dosyaları hazırlık alanına (staging) alıp ilk commit'i yapın:

Terminal
git add .
git commit -m "Ortalama fonksiyonu ve proje iskeleti eklendi"
[main (root-commit) 3f2a91c] Ortalama fonksiyonu ve proje iskeleti eklendi 3 files changed, 17 insertions(+)

GitHub'a gönderin

Terminal
git remote add origin https://github.com/ayseyilmaz/kalite-lab.git
git push -u origin main

Tarayıcıda github.com/ayseyilmaz/kalite-lab sayfasını yenileyin; üç dosyanız orada olmalı.

07

İkinci commit: bir değişikliği kaydedin

5 dakika

ortalama.py dosyasının sonundaki print satırını şöyle değiştirin:

ortalama.py (son satır)
    print(f"Ortalama: {ortalama([70, 85, 90]):.2f}")

Neyin değiştiğini commit'lemeden önce görün:

Terminal
git diff
- print(ortalama([70, 85, 90])) + print(f"Ortalama: {ortalama([70, 85, 90]):.2f}")
Terminal
git add ortalama.py
git commit -m "Çıktı iki ondalık basamakla biçimlendirildi"
git push
git log --oneline
a7c04e2 (HEAD -> main, origin/main) Çıktı iki ondalık basamakla biçimlendirildi 3f2a91c Ortalama fonksiyonu ve proje iskeleti eklendi
İyi commit mesajı ne değiştiğini söyler: “Çıktı iki ondalık basamakla biçimlendirildi”. “düzeltme”, “asdf”, “son hali” gibi mesajlar altı ay sonra kimseye bir şey anlatmaz.

10

Sık karşılaşılan hatalar

Author identity unknown

Git adınızı ve e-postanızı bilmiyor. 4. adımdaki iki git config komutunu çalıştırıp commit'i tekrarlayın.

Support for password authentication was removed

Terminalde GitHub şifrenizi girdiniz; GitHub bunu kabul etmez. 5. adımdaki gh auth login ile giriş yapın ve push'u tekrarlayın.

error: src refspec main does not match any

Henüz hiç commit yapmadan push etmeye çalıştınız ya da dalınızın adı master. Önce git log ile commit olduğunu kontrol edin; dal adı master ise git branch -M main çalıştırın.

! [rejected] main -> main (fetch first)

GitHub'daki depoda sizin bilgisayarınızda olmayan bir commit var; çoğunlukla depo oluştururken README eklendiği için. Şunu çalıştırıp push'u tekrarlayın:

Terminal
git pull --rebase origin main
git push
remote origin already exists

git remote add komutunu ikinci kez çalıştırdınız. Adresi düzeltmek için: git remote set-url origin https://github.com/ayseyilmaz/kalite-lab.git

Commit'lerim profilimde yeşil kare olarak görünmüyor

git config user.email çıktısındaki adres GitHub hesabınızdaki e-postalardan biri değil. Adresi hesabınıza ekleyin ya da config'i düzeltin; yeni commit'ler görünür.

Vim ekranında kaldım (commit mesajı sorulan siyah ekran)

-m olmadan commit yaptınız ve git editör açtı. Çıkmak için Esc tuşuna basıp :q! yazın ve Enter'a basın, sonra git commit -m "mesaj" ile tekrarlayın. 4. adımdaki core.editor ayarı bunun bir daha olmasını önler.
